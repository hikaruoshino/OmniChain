# OmniChain (v7.1.0)

**ファイナルファンタジーXI（Windower 4用） 全22ジョブ・全14武器種対応 自動技連携アシストアドオン**

`OmniChain` は、FFXI Windower 4 向けの自動技連携（スキルチェーン）アシストアドオンです。パーティーメンバーのウェポンスキルや、召喚獣の契約の履行・オートマトンの技をリアルタイムに検知し、**今の連携に繋がるWSを優先リストから自動で選んで発動**します。連携が無いときは、優先リストの最上位WSで連携の始点を作ります。

v7.1.0 では、**自動で入力したWSが失敗したときに理由をその場で知らせる機能**と、**優先リストのWSが使えるかの点検（`//omni check`）**を搭載しました。あわせて、連携判定とWSの連携属性を wiki（[FF11用語辞典](https://wiki.ffo.jp/)）準拠に全面的に見直しています。

## 🌟 主な機能

* **自動技連携（全22ジョブ・全14武器種）**
  * ジョブごとに「武器種」と「WS優先リスト」を設定。TPが設定値（初期値1000）以上になると自動でWSを発動します。
  * 連携窓（8秒）が開いている間は、優先リストを上から評価し、**連携が成立する最初のWS**を選びます。
* **wiki 準拠の連携判定**
  * 連携表・判定順序は [技連携（wiki 341）](https://wiki.ffo.jp/html/341.html) に準拠。先WSの属性 A1→A2→A3 と後WSの属性 B1→B2→B3 を順に照合し、最初に成立したものを採用します。
  * 3連携目以降は、直前に発生した連携だけを判定に使います。
  * 光→光／闇→闇は「もう一度だけ」、極光・黒闇の後はどのWSでも連携しない仕様にも対応。
* **WS・履行・オートマトン技の連携属性データベース (`sc_dict.lua`)**
  * 武器WS 215件（[wiki 307](https://wiki.ffo.jp/html/307.html) の14武器種ページ準拠）
  * 召喚獣の契約の履行 31件（[wiki 332](https://wiki.ffo.jp/html/332.html) 準拠）
  * オートマトンのWS 12件（[wiki 8521](https://wiki.ffo.jp/html/8521.html)・[8522](https://wiki.ffo.jp/html/8522.html) 準拠）
* **連携の検知（パケット＋チャット）**
  * アクションパケット（0x028）の追加効果メッセージで、発生した連携を正確に判定。チャットの「技連携・○○」も併用し、二重処理は自動で防止します。
  * パーティー／アライアンスのメンバーとそのペットの技だけを対象にし、敵の技では連携窓を開きません。
* **撃てないWSは自動で飛ばす（v7.1 新機能）**
  * 優先リストのうち、ペット技（/ws では撃てない）・覚えていないWS・武器が合わないWSは飛ばして、撃てるWSの中で最上位のものを使います。
  * ミス／効果なしだったWSは連携の初段として扱いません。
* **WS 失敗の通知（v7.1 新機能）**
  * 自動入力したWSが発動しない・射程外・TP不足・構えの中断・ミス／効果なしなどを、理由つきの日本語でチャットに知らせます（同じ内容は10秒に1回にまとめて表示）。
* **優先リストの点検（v7.1 新機能）**
  * 優先リストに、ペット技・名前の誤り・覚えていない／武器が合わないWSが無いかを点検します。読み込み時とジョブ変更時に自動で行い、`//omni check` でいつでも確認できます。
* **Web 設定エディタ (`OmniChain_GUI.html`)**
  * ブラウザで開いて、ジョブごとの武器種・WS優先リスト・最小TPなどを編集し、`omnichain_config.json` として書き出せます。
* **クライアント安定性**
  * パケット・描画・コマンドなどのイベント処理をエラー捕捉で保護し、1回のエラーでアドオン全体が止まらないようにしています。エリアチェンジ・ログアウト・アンロード時に状態を確実に破棄します。

## 🚀 インストール方法

1. GitHub のページで **Code → Download ZIP** を押して、ファイル一式をダウンロードします。
2. ZIP を解凍し、フォルダー名を **`OmniChain`** にします。
   ※ GitHub の ZIP は `OmniChain-main` という名前で解凍されるため、`-main` を消してください。フォルダー名とアドオン名が違うと読み込めません。
3. Windower 4 の addons フォルダーに置きます：
   `Windower4/addons/OmniChain/OmniChain.lua`
   `Windower4/addons/OmniChain/sc_dict.lua`
4. ゲーム内のコンソールまたはマクロで読み込みます：
   `//lua load OmniChain`
5. 毎回自動で読み込みたい場合は、`Windower4/scripts/init.txt` に次の 1 行を追加します：
   `lua load OmniChain`

※ 旧バージョンから更新する場合は、ファイルを上書きしてから `//lua reload OmniChain` で再読み込みしてください。自分で編集した `omnichain_config.json` がある場合は、上書き前に退避しておいてください。

## ⚙️ 設定方法

### ジョブ別の武器種・WS優先リスト
1. `OmniChain_GUI.html` をブラウザで開き、ジョブごとの武器種とWS優先リスト（上ほど優先）を編集します。
2. 書き出した `omnichain_config.json` を `OmniChain/` フォルダー（または `OmniChain/data/`）に置きます。
3. ゲーム内で `//omni reload` を実行すると反映されます（ジョブ変更時にも自動で読み込みます）。

`omnichain_config.json` から読み込まれる項目は `profiles`（武器種・WS優先リスト）、`min_tp`、`wait_delay` です。JSON が無い場合、`profiles` はアドオン内蔵の既定値を、`min_tp`・`wait_delay` は `data/settings.xml` の設定を使います（WS優先リストは `settings.xml` には保存されません）。

### 主な設定項目 (`data/settings.xml`)

| 項目 | 初期値 | 説明 |
| :--- | :--- | :--- |
| `enabled` | `true` | 自動連携の ON / OFF（`//omni on` / `off` で切替） |
| `min_tp` | `1000` | WS を発動する最小TP |
| `wait_delay` | `1.2` | WS 発動後、次の発動までの待ち時間（秒） |
| `auto_mode` | `flexible` | `flexible`: 連携窓中に繋がるWSが無いときも最上位WSを撃つ ／ それ以外: 繋がるWSが無ければ撃たない |

## 💻 コマンド一覧 (`//omni` または `//omnichain`)

### 基本操作

| コマンド | 説明 | 実行例 |
| :--- | :--- | :--- |
| `//omni on` / `//omni off` | 自動連携の ON / OFF（`enable` / `disable` も可） | `//omni on` |
| `//omni hud [on\|off]` | 連携HUD（連携窓・次に撃つWS）の表示切替 | `//omni hud on` |
| `//omni size <数>` | 連携HUDの文字サイズ (6〜40)。HUDの上でマウスホイール、または右下の角「◢」のドラッグでも変更でき、大きさは保存されます | `//omni size 9` |
| `//omni reload` | `omnichain_config.json` を読み直す | `//omni reload` |
| `//omni status` | 現在の設定・ジョブ・優先リストを表示 | `//omni status` |
| `//omni check` | 優先リストのWSが今使えるかを点検 | `//omni check` |

### チャットに出る知らせ

| 表示 | 意味 |
| :--- | :--- |
| `WS_TIMEOUT` | 自動で入力したWSが4秒以内に発動しなかった（WS名・距離・行動不能などを確認） |
| `WS_FAIL` | WSが失敗した（射程外・遠すぎる・TP不足・武器違い・構えの中断など） |
| `WS_RESULT` | WSがミス／効果なしだった、または入力と違うWSが出た |
| `CHECK` | 優先リストに撃てないWSがある |
| `EXECUTE` | 自動で撃とうとしたWSが今は使えない（武器不一致・未習得など） |
| `CONFIG` | `omnichain_config.json` の書き方に誤りがあり読み込めなかった |

詳しくは同梱の `COMMANDS.txt` を参照してください。

## 🎯 WS 選択ロジック (v7.1.0)

TP が最小TP以上で、前回の発動から待ち時間が経過していると、次の順でWSを選びます。

1. **撃てるWSに絞り込み**: ペット技・覚えていないWS・武器が合わないWSを除外
2. **連携窓が開いている場合**: 優先リストを上から評価し、今の連携属性に対して**連携が成立する最初のWS**を選択
3. **繋がるWSが無い場合**: `auto_mode` が `flexible` なら撃てる最上位WSを発動（それ以外は撃たない）
4. **連携窓が無い場合**: 撃てる最上位WSで連携の始点を作る

### 連携の判定ルール（wiki 341 準拠）
* 先WSの属性 A1, A2, A3 と後WSの属性 B1, B2, B3 を **A1+B1 → A1+B2 → A1+B3 → A2+B1 …** の順に照合し、最初に成立したものを採用
* 2連携目以降は、直前に発生した連携だけを A1 として判定
* 光→光／闇→闇は「もう一度だけ」成立し、以降どのWSでも連携しない
* 極光／黒闇の後も連携しない
