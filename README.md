# OmniChain (v7.0.0)

**全22ジョブ ＆ 全14武器種 ＋ プライムWS ＋ からくり士マトン ＋ 召喚士契約の履行 対応 自動技連携アドオン**

`OmniChain` は、FFXI Windower 4 向けの次世代自動技連携・連携ナビゲーションアドオンです。
プレイヤー自身の武器スキルだけでなく、**からくり士のオートマトンウェポンスキル（12種）** や **召喚士の召喚獣による「契約の履行」（30種）**、さらには全武器種の**プライムウェポンWS（14種）**の各種連携属性を完全網羅し、マルチパケット解析（Category 3/11/13）によって最高のレベル3・レベル4連携（光・闇・極光・黒闇）へ自動で追尾・発動・ナビゲートします。

---

## 🌟 主な特徴 (v7.0.0)

* **全230種 完全公式正確表記対応**
  * 片手刀: `臨`, `烈`, `滴`, `凍`, `地`, `影`, `迅`, `天`, `空`, `生者必滅`, `カムハブリ`, `秘`, `瞬`, `是生滅法` (プライム)
  * 両手刀: `壱之太刀・燕飛`, `弐之太刀・鋒縛`, `参之太刀・轟天`, `四之太刀・陽炎`, `五之太刀・陣風`, `六之太刀・光輝`, `七之太刀・雪風`, `八之太刀・月光`, `九之太刀・花車`, `零之太刀・回天`, `十之太刀・乱鴉`, `十一之太刀・鳳蝶`, `十二之太刀・照破`, `祖之太刀・不動`, `絶之太刀・無名` (プライム)
* **プライムウェポンWS（14武器種）完全組み込み**
  * 『マルカラ』『ルースレスストローク』『インペラトル』『フィンブルヴェト』『ブリッツ』『ディザスター』『ジ・オリジン』『ダーマット』『是生滅法』『絶之太刀・無名』『ダグダ』『オシャラ』『シャルヴ』『ジ・エンド』
* **からくり士 オートマトンWS（12種）追尾**
  * 『ストリングシュレッダー』『ボーンクラッシャー』『アーマーシャッタラー』『マジックモーター』『カニバルブレード』など、インヒビターやマニューバ状態に応じたマトンWSを即時キャッチし、マスターの最適締めWSを算出。
* **召喚士 契約の履行（30種）パケット検知**
  * イフリート『フレイムクラッシュ』【核熱】、ラムウ/ガルーダ/セイレーン『ボルトストライク』『プレデタークロー』『ヒステリックアサルト』【分解】などの履行トスに合わせ、他ジョブが光・闇連携を叩き込むオートナビゲーション。
* **Web Config Editor (`OmniChain_GUI.html`) 付属**
  * ブラウザ上で視覚的にドラッグ＆ドロップでWS優先順位（Priority）を並び替え、`omnichain_config.json` を保存・読み込み可能。

## 🚀 インストール方法

1. `OmniChain_v7.0_Full_Package.zip` を解凍します。
2. `Windower4/addons/OmniChain/` フォルダーを作成し、全ファイルを配置します。
3. ゲーム内でコマンドを実行して読み込みます：
   `//lua load OmniChain`
