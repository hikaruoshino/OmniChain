# OmniChain (v7.0.3)

FFXI（Final Fantasy XI）Windower 4 用の全22ジョブ・14武器種・からくり士オートマトンWS・召喚士契約の履行対応 自動技連携・ナビゲーションアドオンです。

## 🌟 主な機能

1. **全14武器種 ＆ 全230種類以上のウェポンスキル完全対応**
   * プライムウェポンWS（『マルカラ』『是生滅法』『絶之太刀・無名』『フィンブルヴェト』等14種）とその固有3重連携属性に対応。
   * 片手刀（『臨』『迅』『瞬』等）および両手刀（『壱之太刀・燕飛』〜『祖之太刀・不動』）のインゲーム正式名称表記に100%完全準拠。

2. **からくり士 オートマトンWS (12種) 完全連携追尾**
   * 白兵戦・射撃戦・魔法戦・汎用フレームの全WSをマトリクス化。
   * アタッチメント（インヒビター等）によるトス待ち・即撃ちをリアルタイム解析し、マスターの最適WS（光・闇連携など）を判定・実行。

3. **召喚士 召喚獣「契約の履行」 (30種) パケット直接解析**
   * イフリート、ラムウ、ガルーダ、タイタン等の攻撃履行パケット（Category 11/13）をキャッチし、履行トスからの自動締め連携を追尾。

4. **Web Config Editor (`OmniChain_GUI.html`) 同梱**
   * ブラウザ上で全22ジョブのWS優先順位をドラッグ＆ドロップ編集。`omnichain_config.json` として一括保存・読み込み可能。
   * 全22ジョブの初期プロファイル完備 ＆ 大容量スクロール枠で技選択がさらにスムーズに。

5. **安全設計 ＆ POLクラッシュ防御**
   * 排他送信ロック・型強制変換ガード (`get_safe_number`) により比較エラーやPOL落ちのリスクを排除。
   * 初期起動時はHUDオーバーレイ非表示（OFF）に設定 (`//omni hud` で切替可能)。

## 💻 コマンド一覧 (`//omni` または `//omnichain`)

| コマンド | 説明 |
| :--- | :--- |
| `//omni enable` / `disable` | 自動連携機能の ON / OFF 切替 |
| `//omni hud` | HUDオーバーレイ表示の ON / OFF 切替 |
| `//omni reload` | `omnichain_config.json` の再読み込み |
| `//omni job <JOB>` | 対象ジョブの切り替え (例: `//omni job SAM`) |
| `//omni weapon <武器種>` | 選択武器種の切り替え (例: `//omni weapon 両手刀`) |
| `//omni tp <1000~3000>` | 最小発動TPの設定 |
| `//omni status` | 現在の設定ステータス確認 |
