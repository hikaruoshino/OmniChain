# OmniChain (v7.0.3)

全22ジョブ、全14武器種、からくり士オートマトンWS、および召喚士契約の履行に完全対応した自動技連携判定・実行Windower 4アドオンです。

## 🔗 公式GitHubリポジトリ
👉 [https://github.com/hikaruoshino/OmniChain](https://github.com/hikaruoshino/OmniChain)

## 特長
- **全22ジョブ完全対応**: 全職種の武器種および優先WSプロファイルを完備。
- **プライムウェポンWS完全対応**: 全14武器種のプライムWSとその独自の3重連携属性に対応。
- **からくり士 ＆ 召喚士 ペット連携自動追尾**: オートマトンWS（12種）および契約の履行（30種）のパケットをリアルタイム検知して連携追従。
- **Web Config Editor (`OmniChain_GUI.html`)**: 直感的なドラッグ＆ドロップ編集および大容量スクロール追加リスト。
- **100% POLクラッシュ防御 ＆ 比較エラー完全防止**: DirectWrite UTF-8 HUD描画、Shift-JIS変換、安全な数値型キャスト処理。

## 導入方法
1. `Windower4/addons/` フォルダー内に `OmniChain` フォルダーを配置します。
2. ゲーム内で `//lua load OmniChain` を実行します。
3. HUD表示切り替えは `//omni hud` を使用します。
