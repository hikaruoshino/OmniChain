# OmniChain v6.0.0 - FFXI 万能自動技連携アドオン

Windower 4 公式 API・パケット・テキスト描画仕様に完全適応した、全22ジョブ＆全14武器種対応の自動技連携アドオンです。

## ✨ 主な特徴

- **全22ジョブ ＆ 全14武器種対応**: FFXI内の全メインジョブ・武器種に対応。
- **WS優先順位 (Priority) 管理**: 設定した優先度の高いWSから順に連携評価を実施。
- **PT・多人数連携同期**: パケット (0x028) 監視により、味方のWSや技連携発生をミリ秒追跡。
- **Web GUI設定エディタ**: `OmniChain_GUI.html` をブラウザで開いて簡単カスタマイズ。
- **100% 安全設計**: 排他ロックガードによりPOLクラッシュ・文字化け（豆腐化）を徹底防御。

## ⚙️ コマンド一覧 (`//omni` または `//omnichain`)

- `//omni enable` / `disable`: 自動連携機能の ON / OFF 切替
- `//omni job <WAR|PLD...>`: 対象ジョブの変更
- `//omni weapon <両手斧|片手剣...>`: 装備武器種の変更
- `//omni priority <WS1> <WS2>...`: WS優先順位の設定
- `//omni tp <1000~3000>`: 最小発動TP設定
- `//omni status`: 現在の設定確認
