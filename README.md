# OmniChain (v7.3.0)

**ファイナルファンタジーXI（Windower 4用） 全22ジョブ・全14武器種対応 自動技連携アシストアドオン**

`OmniChain` は、FFXI Windower 4 向けの自動技連携（スキルチェーン）アシストアドオンです。パーティーメンバーのウェポンスキルや、召喚獣の契約の履行・オートマトンの技をリアルタイムに検知し、**今の連携に繋がるWSを優先リストから自動で選んで発動**します。連携が無いときは、優先リストの最上位WSで連携の始点を作ります。

v7.2.0 では、**1回目のWSを自分で撃ち、その後を自動で繋げる「手動始点モード」**を追加しました。あわせて、**始点専用WSの設定（`opener_only`）**、**イオニック武器のアフターマスで付く光／闇への対応**、**敵が変わったときの連携のやり直し**を入れ、侍が1人で6連携（鳳蝶→陣風→照破→照破→花車→不動）を組めるようになっています。

v7.1.0 では、連携判定とWSの連携属性を wiki（[FF11用語辞典](https://wiki.ffo.jp/)）準拠に全面的に見直し、WSが撃てなかったときの理由を日本語で知らせるようにしました。

## 🌟 主な機能

* **自動技連携（全22ジョブ・全14武器種）**
  * ジョブごとに「武器種」と「WS優先リスト」を設定。TPが設定値（初期値1000）以上になると自動でWSを発動します。
  * 連携窓（8秒）が開いている間は、優先リストを上から評価し、**連携が成立する最初のWS**を選びます。
* **wiki 準拠の連携判定**
  * 連携表・判定順序は [技連携（wiki 341）](https://wiki.ffo.jp/html/341.html) に準拠。先WSの属性 A1→A2→A3 と後WSの属性 B1→B2→B3 を順に照合し、最初に成立したものを採用します。
  * 3連携目以降は、直前に発生した連携だけを判定に使います。
  * 光→光／闇→闇は「もう一度だけ」、極光・黒闇の後はどのWSでも連携しない仕様にも対応。
* **WS・履行・オートマトン技の連携属性データベース (`sc_dict.lua`)**
  * 武器WS 215件（[wiki 307](https://wiki.ffo.jp/html/307.html) の14武器種ページ準拠）
  * 召喚獣の契約の履行 31件（[wiki 332](https://wiki.ffo.jp/html/332.html) 準拠）
  * オートマトンのWS 12件（[wiki 8521](https://wiki.ffo.jp/html/8521.html)・[8522](https://wiki.ffo.jp/html/8522.html) 準拠）
* **連携の検知（パケット＋チャット）**
  * アクションパケット（0x028）の追加効果メッセージで、発生した連携を正確に判定。チャットの「技連携・○○」も併用し、二重処理は自動で防止します。
  * パーティー／アライアンスのメンバーとそのペットの技だけを対象にし、敵の技では連携窓を開きません。
* **手動始点モード（v7.2 新機能）**
  * `//omni start manual` で、1回目のWSは自分で撃ち、その後を自動で繋げます。他の人のWSが始点になった場合も、その連携属性に続けて自動連携します。
  * 自動WSは直前のWSから6秒待って撃つので（`//omni wait` で変更）、他の人の横槍が入ってもそれに合わせて判定し直します。
* **始点専用WS・イオニック対応・敵ごとの連携（v7.2 新機能）**
  * ジョブ設定の `"opener_only": true` で、優先リストの先頭WSを始点専用にできます（連携中は2番目以降を優先）。
  * イオニック武器（14種）でそのWSを撃つと、アフターマスで付く光／闇も含めて連携を判定します。
  * 連携は敵ごとに記録し、倒して別の敵に移ったときは前の敵の連携を続けず始点から撃ち直します。
  * チャットの「技連携・○○」が数秒遅れて届いて新しい状態を上書きする問題を修正しました（パケットを優先）。
* **撃てないWSは自動で飛ばす（v7.1 新機能）**
  * 優先リストのうち、ペット技（/ws では撃てない）・覚えていないWS・武器が合わないWSは飛ばして、撃てるWSの中で最上位のものを使います。
  * ミス／効果なしだったWSは連携の初段として扱いません。
* **エラー・警告の通知**
  * 自動入力したWSが発動しない・射程外・TP不足・構えの中断などの失敗理由を、日本語でチャットに知らせます（同じ内容は10秒に1回にまとめて表示）。
* **Web 設定エディタ (`OmniChain_GUI.html`)**
  * ブラウザで開いて、ジョブごとの武器種・WS優先リスト・最小TPなどを編集し、`omnichain_config.json` として書き出せます。
* **クライアント安定性**
  * パケット・描画・コマンドなどのイベント処理をエラー捕捉で保護し、ログはまとめて書き出す方式で負荷を抑えています。エリアチェンジ・ログアウト・アンロード時に状態を確実に破棄します。

## 🚀 インストール方法

1. 最新の `OmniChain` ファイル一式を入手します。
2. Windower 4 の addons フォルダー内に `OmniChain` フォルダーを作成し、配置します：
   `Windower4/addons/OmniChain/OmniChain.lua`
   `Windower4/addons/OmniChain/sc_dict.lua`
3. ゲーム内のコンソールまたはマクロで読み込みます：
   `//lua load OmniChain`

※ 旧バージョンから更新する場合は `//lua reload OmniChain` で再読み込みしてください。

## ⚙️ 設定方法

### ジョブ別の武器種・WS優先リスト
1. `OmniChain_GUI.html` をブラウザで開き、ジョブごとの武器種とWS優先リスト（上ほど優先）を編集します。
2. 書き出した `omnichain_config.json` を `OmniChain/` フォルダー（または `OmniChain/data/`）に置きます。
3. ゲーム内で `//omni reload` を実行すると反映されます（ジョブ変更時にも自動で読み込みます）。

`omnichain_config.json` から読み込まれる項目は `profiles`（武器種・WS優先リスト）、`min_tp`、`wait_delay` です。JSON が無い場合、`profiles` はアドオン内蔵の既定値を、`min_tp`・`wait_delay` は `data/settings.xml` の設定を使います（WS優先リストは `settings.xml` には保存されません）。

ジョブごとに `"opener_only": true` を書くと、優先リストの先頭WSを**始点専用**にします。連携中は2番目以降から先に探し、どれもつながらないときだけ先頭WSを使います（例: 侍で鳳蝶を始点にし、炸裂の後は鳳蝶ではなく照破で重力にする）。この項目は手で `omnichain_config.json` に書き足してください（設定エディタは扱いません）。

### 主な設定項目 (`data/settings.xml`)

| 項目 | 初期値 | 説明 |
| :--- | :--- | :--- |
| `enabled` | `true` | 自動連携の ON / OFF（`//omni on` / `off` で切替） |
| `min_tp` | `1000` | WS を発動する最小TP |
| `wait_delay` | `1.2` | WS 発動後、次の発動までの待ち時間（秒） |
| `start_mode` | `auto` | `auto`: 1回目のWSも自動で撃つ ／ `manual`: 1回目は自分で撃つ（`//omni start` で切替） |
| `follow_wait` | `6.0` | `manual` のとき、直前のWSが当たってから自動WSを撃つまでの秒数（`//omni wait` で変更） |
| `trust_solo` | `true` | 一人連携を狙うフェイスが条件のアビリティを使ったら、終わるまで自動WSを撃たない（`//omni solo` で切替） |
| `solo_start_wait` | `12.0` | フェイスがアビリティを使ってから、最初のWSが出るまで待つ秒数（`//omni solo start` で変更） |
| `solo_gap` | `11.0` | フェイスのWSから次のWSまで待つ秒数。過ぎたら一人連携は終わりとみなす（`//omni solo gap` で変更） |
| `auto_mode` | `flexible` | `flexible`: 連携窓中に繋がるWSが無いときも最上位WSを撃つ ／ それ以外: 繋がるWSが無ければ撃たない |
| `debug_logging` | `true` | ログファイルへの記録 |

## 🎯 WS 選択ロジック (v7.2.0)

TP が最小TP以上で、前回の発動から待ち時間が経過していると、次の順でWSを選びます。

1. **撃てるWSに絞り込み**: ペット技・覚えていないWS・武器が合わないWSを除外
2. **連携窓が開いている場合**: 優先リストを上から評価し、今の連携属性に対して**連携が成立する最初のWS**を選択
3. **繋がるWSが無い場合**: `auto_mode` が `flexible` なら撃てる最上位WSを発動（それ以外は撃たない）
4. **連携窓が無い場合**: 撃てる最上位WSで連携の始点を作る（`start_mode` が `manual` のときは撃たずに始点を待つ）

### 手動始点モード（`//omni start manual`）
* 1回目のWSは自分で撃つ。他の人のWSが始点になった場合も、その連携属性に続けて自動連携する
* 自動WSは、直前のWS（誰のものでも）が当たってから `follow_wait` 秒（初期値6秒）待って撃つ。待っている間に他の人のWSが入ったら、その結果で判定し直し、待ち時間もそこから数え直す
* 待ってから撃つため、連携窓は受付の上限の10秒として扱う（BG-Wiki: 3〜10秒）。`auto` は従来どおり8秒

### 連携の判定ルール（wiki 341 準拠）
* 先WSの属性 A1, A2, A3 と後WSの属性 B1, B2, B3 を **A1+B1 → A1+B2 → A1+B3 → A2+B1 …** の順に照合し、最初に成立したものを採用
* 2連携目以降は、直前に発生した連携だけを A1 として判定
* 光→光／闇→闇は「もう一度だけ」成立し、以降どのWSでも連携しない
* 極光／黒闇の後も連携しない（始点WSのイオニックの光／闇に光／闇WSを重ねた連携も、光→光／闇→闇として終わる）
* 連携は敵ごと。連携が付いている敵と今の敵が違うときは、連携窓が無いものとして始点から撃つ
* **イオニック武器**: 自分がイオニック武器でそのWS（例: 童子切安綱の照破）を撃つと、アフターマスの光／闇を属性の先頭に加えて判定する（発動させたWS自身にも付く）。他人の武器は分からないため、パーティーメンバーのイオニックWSには加えない
* **連携の受け取り**: パケットを正とする。チャットの「技連携・○○」は数秒遅れて届くことがあるため、パケットで連携状態を更新してから10秒間は無視する

### フェイスの技と一人連携待ち（v7.3.0）
* フェイスの技も、プレイヤーのWSと同じように連携の始点・途中として扱う。連携属性はゲームのリソース（`res/monster_abilities.lua`）から読み、リソースに属性が無い技（ミュモルII の 2 技）だけ `sc_dict.lua` の `TRUST_WS_EXTRA` で補う。連携属性の無い技は、連携の始点にしない。
* **一人連携を狙うフェイス**（イロハ・イロハII・ノユリ・ギルガメッシュ・アークGK）が、条件のアビリティを使ったら、一人連携が終わるまで自動WSを撃たずに待つ。

| フェイス | 合図になるアビリティ | 一人連携の最後の技 |
| :--- | :--- | :--- |
| イロハ / イロハII | 黙想 | 天つ水影流・月輪 |
| ノユリ | 石火之機 | 零之太刀・回天 |
| ギルガメッシュ | 石火之機 | （不明） |
| アークGK | 黙想・葉隠・石火之機 | （決まっていない。2 発で終わる） |

* テンゼンも一人連携をするが、技の順番が毎回違い 40 秒ほど続くため、待たずに割り込む。
* 待つのをやめる条件: 最後の技が出た ／ 光→光・闇→闇で連携が閉じた ／ フェイスのWSが `solo_gap` 秒来なかった ／ アビリティの後 `solo_start_wait` 秒たってもWSが出なかった。
* アークGK は 2 発撃ったところで待ちを解く。2 発目で出来た連携には、自分のWSを続ける。
* 回復・強化の技（イロハのライズフロムアシェズなど）は、一人連携の技として数えない。
* 待っている間、HUD に「一人連携待ち: フェイス名（あと ○ 秒）」と出る。経過はログの `TRUST_SOLO` に残る。

### 続けずに始点から撃つ技（v7.3.0）
* 次の技のあとは、自分のWSを重ねても連携しなかった（ゲーム内で繰り返し確認）。そこで連携は終わりとして扱い、次は始点から組み直す。対象は `sc_dict.lua` の `NO_FOLLOW` で変えられる。
  * **イロハ / イロハII の月輪**: 一人連携の最後でも、それ以外でも、3〜7 秒後のWSが 1 回も連携しなかった。
  * **セルテウスの技**（リヴァレーション・ルミナスランス）: 4〜5 秒後のWSが 13 回とも連携しなかった。
* フェイス同士はこれらの技のあとも連携する。その結果はこれまでどおり読み取り、自分のWSを続ける。

### そのほかの連携の扱い（v7.3.0）
* **ジャンプ類**: ジャンプ・ハイジャンプ・スーパージャンプなど、WSと同じ形で届くアビリティを、WSと読み違えないようにした。
* **渾然一体**: 敵が連携待機になったあとの最初のWSは、直前の属性に関係なく連携になる。発生した連携を読み取り、その属性に続くWSを撃つ。光／闇を持つWSで出来た光／闇には続けない。
* **パーティ外の人のWS**: 七支公のようにパーティ外の人と一緒に戦う敵では、自分がターゲットしている敵に撃たれたパーティ外のWSも連携に数える。

## 📜 更新履歴（Changelog）

* **v7.3.0 (2026-10-10)**
  * **フェイスの一人連携待ち**: 一人連携を狙うフェイス 5 体（イロハ・イロハII・ノユリ・ギルガメッシュ・アークGK）が黙想・葉隠・石火之機を使ったら、一人連携が終わるまで自動WSを待つ（`//omni solo`）。
  * **アフターマスの確認**: イオニックWSの光／闇は、今アフターマスが付いているときだけ連携の判定に使う。フェイスや他の人の光／闇、連携で出来た光／闇を締めるときは、元から光／闇を持つWS（不動など）を先に選ぶ。自分のイオニックWSから続ける場合（照破→照破＝極光）はこれまでどおり。
  * **受付時間の短縮に対応**: 連携が続くたびに受付が 1 秒ずつ短くなるものとして扱い、手動始点モードの待ち時間を、受付が閉じる 2 秒前までに撃てるよう自動で詰める（最短 3 秒）。
  * **続けない技**: イロハの月輪とセルテウスの技のあとは、自分のWSが連携しないため、続けずに始点から撃つ。
  * **最短の待ち時間**: 直前のWS（誰のものでも）から 3.3 秒は自動WSを撃たない（`//omni minfollow`）。連携の受付が開く前に撃って、連携を切ってしまうのを防ぐ。
  * **渾然一体・ジャンプ類・パーティ外のWS**: 渾然一体の連携待機、WSと同じ形で届くジャンプ類、パーティ外の人が同じ敵に撃ったWSを正しく扱う。
  * フェイスの技のうち、リソースに連携属性が無い 2 技（ミュモルII）を補った。フェイス 111 体・303 技の連携属性を wiki.ffo.jp と突き合わせた。
