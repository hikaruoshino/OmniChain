================================================================================
 OmniChain v7.2.0 コマンド一覧
================================================================================
 コマンドは //omni または //omnichain で始めます。
 チャット内で //omni だけを入力すると簡易ヘルプが出ます。
 ON/OFF を指定しないコマンドは、入力するたびに ON と OFF が切り替わります。


--------------------------------------------------------------------------------
■ 基本操作
--------------------------------------------------------------------------------
 //omni enable  (または //omni on)     自動連携を ON
 //omni disable (または //omni off)    自動連携を OFF
 //omni start manual                  1回目のWSは自分で撃つ (手動始点モード)
                                      自分や他の人のWSが始点になったら、その連携属性に
                                      続けて自動連携する。自動WSは直前のWSが当たってから
                                      待ち時間ぶん待って撃つ (他の人の横槍を待つため)。
                                      連携窓は10秒として扱う
 //omni start auto                    1回目も自動で撃つ (初期値・今までどおり)
 //omni start                         今の始点モードを表示
 //omni wait <秒>                     手動始点モードの待ち時間 (0〜9、初期値 6)
 //omni hud [on|off]                  連携 HUD (連携窓・次に撃つWS) の表示切替
 //omni size <数>                     連携 HUD の文字サイズ (6〜40)。HUD の上でホイール、
                                       または右下の角「◢」のドラッグでも変更可 (大きさは保存)
 //omni reload                        omnichain_config.json を読み直す
 //omni status                        現在の設定・ジョブ・優先リスト・監視状態を表示


--------------------------------------------------------------------------------
■ リアルタイム監視
--------------------------------------------------------------------------------
 //omni mon [on|off]                  監視ウィンドウの表示切替
                                      (エラー/警告の件数と直近の記録を表示。
                                       ドラッグで移動でき、位置はアドオン終了時に保存)
 //omni mon packet [on|off]           技パケットの詳細記録の切替 (初期値 OFF)
                                      0x028: パーティーのWS・WS構え・TP技・ペット技
                                      0x029: 自分宛ての行動メッセージ
 //omni mon chat [on|off]             エラー/警告をチャットにすぐ出すかの切替 (初期値 ON)
 //omni mon lines <数>                監視ウィンドウの行数 (1〜30、初期値 10)
 //omni mon clear                     監視の履歴と件数をリセット


--------------------------------------------------------------------------------
■ ログ
--------------------------------------------------------------------------------
 //omni log                           記録の ON/OFF・保存先・起動後の件数を表示
 //omni log on / off                  ファイルへの記録の切替
 //omni log clear                     ログファイルを空にする
 //omni log tail [数]                 直近の記録をチャットに表示 (初期値 10、最大 30)
 //omni log err [数]                  エラーと警告だけをチャットに表示

 保存先 : addons/OmniChain/omnichain_debug.log
          1MB を超えると omnichain_debug.old.log に移します。
 書き方 : [日時] [種類] [分類] 内容
          種類は ERROR / WARN / INFO / PKT


--------------------------------------------------------------------------------
■ Windower の console.log 監視 (他のアドオンのエラー)
--------------------------------------------------------------------------------
 //omni console [数]                  console.log の最近のエラーを一覧表示 (初期値 5、最大 20)
                                      起動前に出たエラーも含み、対処のヒントも出します
 //omni console on / off              console.log 監視の切替 (初期値 ON)

 監視中は5秒ごとに console.log の追記分を読み、GearSwap など他のアドオンの
 エラーが出ると [OmniChain:WARN] CONSOLE としてチャットに知らせます。
 (Lua からはファイルの更新日時が取れないため、ファイルサイズの増加で判定しています)


--------------------------------------------------------------------------------
■ 点検
--------------------------------------------------------------------------------
 //omni check                         優先リストの WS が今使えるかを点検
                                      ・ペット技 (/ws では撃てない)
                                      ・sc_dict / res に無い名前
                                      ・覚えていない / 武器が違う WS
 ※ 読み込み時とジョブ変更の5秒後にも自動で点検します。


--------------------------------------------------------------------------------
■ チャットに出る警告の意味
--------------------------------------------------------------------------------
 WS_TIMEOUT   自動で入力したWSが4秒以内に発動しなかった
              (WS名の誤り・距離・行動不能などを確認)
 WS_FAIL      WSが失敗した (射程外・遠すぎる・TP不足・武器違い・構えの中断など)
 WS_RESULT    WSがミス/効果なしだった、または入力と違うWSが出た
 CHECK        優先リストに撃てないWSがある
 CONSOLE      console.log に他のアドオンのエラーが出た (「対処:」にヒント)
 PERF         処理が重いフレームがあった (30秒に1回まとめて報告)
 ERROR        OmniChain 内部の Lua エラー (詳しい内容はログファイルに記録)

 同じ内容の警告は10秒に1回だけ表示し、その間の回数を「他 n 回」と添えます。


--------------------------------------------------------------------------------
■ 自動連携の動き (v7.2.0 の変更点)
--------------------------------------------------------------------------------
 ・//omni start manual で、1回目のWSは自分で撃ち、その後を自動で繋げられます。
 ・omnichain_config.json のジョブ設定に "opener_only": true を書くと、
   優先リストの先頭WSを始点専用にします (連携中は2番目以降を優先)。
 ・イオニック武器でそのWSを撃つと、アフターマスの光/闇も含めて判定します。
 ・倒して別の敵に移ったときは、前の敵の連携を続けず始点から撃ち直します。


--------------------------------------------------------------------------------
■ 自動連携の動き (v7.1.0 の変更点)
--------------------------------------------------------------------------------
 ・優先リストのうち、ペット技・覚えていないWS・武器が違うWSは飛ばして、
   撃てるWSの中で一番上のものを使います。
 ・ミス/効果なしだったWSは連携の初段として扱いません。
